The kit every agent gets
Five Squircle commands, the same for Claude and Codex, app agents and workers.
1
squircle draw
Boxes-and-arrows pictures from a short spec: now, proposed (added · moved · removed · odd in red), and problem (you did / app does / it should). Pearl, phone width.
→ PNGs in plans/<item>/
2
squircle plan ITEM
Hands in the plan: a few sentences, the pictures, numbered changes, each of your asks tied to a change. Refuses an ask left uncovered.
→ round N waits for Approve plan
3
squircle film ITEM --change 2
Films one change on main and on the branch through the simulator lease, picks before/after frames, measures jumps. A recorder error fails the call loudly.
→ films and frames tied to change 2
4
squircle review ITEM
Starts the independent reviewer as a T3 worker (Astra on Codex, per app). Squircle hands it the plan, diff, films and app rules; it answers PASS / REVISE / BLOCKED with one picture per finding and plan vs actual.
→ review round for commit X
5
squircle merge ITEM
Merges exactly the approved commit, and the plan folder with it. The only way onto main.

ENFORCED, NOT ASKED
